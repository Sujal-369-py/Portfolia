# Sujal's Portfolio

A high-end, premium portfolio website for an AI Developer and Software Engineer. Built with modern web technologies and a focus on visual excellence and interactivity.

## ✨ Features

- **Modern Aesthetic**: Deep space theme with vibrant HSL colors and glassmorphism.
- **Dynamic Background**: Lightweight canvas-based particle system for a subtle, engaging background.
- **Interactive Elements**: 3D card tilt effects and magnet interactions on links and buttons.
- **Text Scramble Animation**: engaging hero section with text scramble effects on load.
- **Responsive Design**: Mobile-first approach with a custom burger menu and optimized layouts for all screen sizes.
- **SEO Optimized**: Semantic HTML and meta tags for better search engine visibility.

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom design system, animations, and layouts.
- **JavaScript (ES6+)**: Custom interactive logic, particle system, and scroll effects.
- **Font Awesome**: Industry-standard icons.
- **Google Fonts**: Modern typography (Outfit).

## 🚀 Getting Started

Simply open `index.html` in your browser to view the portfolio.

```bash
# Clone the repository
git clone https://github.com/Sujal-369-py/Portfolia.git

# Navigate to the project
cd Portfolia

# Open index.html
open index.html
```

## 📱 Mobile Preview

The website is fully responsive and features a custom navigation menu for mobile devices.
